# ケアプラン (居宅サービス計画書) の受け渡し場所

ほのぼの NEXT【ケアマネ】→ 右端の **CSV** タブ から出したものを置く。

```
ケアプラン/<拠点>/careplan1.CSV   第1表  総合的な援助の方針・利用者及び家族の意向・作成者
ケアプラン/<拠点>/KAIGO1.CSV      第2表  課題・長期目標・短期目標・サービス内容・頻度・期間
```

拠点名は `伝送データ/` と揃える (船橋 / 八千代 / 花見川 / 四街道 / 高品 / おゆみ野 /
ちはら台 / 五井 / K姉 / 姉ム / 袖ケ浦 / 木更津 / 大網 / 茂原 / いすみ)。

## 出すときの注意

- **ファイル名が固定**なので、事業所ごとにフォルダを分けないと上書きされる
- **期間を広く取る** (2024/01〜 くらい)。既定のままだと直近に登録し直した人しか出ず、
  船橋で 251 名中 147 名しか出なかった。期間を広げて 279 名になり 250 名をカバー。
  それでも 1 名 (山中敏子) が出ないので、更新が古い人はさらに遡る必要がある
- 予防は事業所名が `…(予防)` で別に出る。同じファイルに混ざる

## なぜ要るか

一括生成 (請求 → レセプト) は **有効なケアプランを持つ利用者だけ**を対象にする。
プランが無いと請求が作られないので、移行時に入れておく必要がある。
船橋で 4 名 (坂田茂・小山よしい・北村弘美・野沢ハツエ) が 84,408 円ぶん落ちた。

## キー

`保険者番号 + 被保険者番号` で第1表・第2表・当方の利用者を結合する。
⚠ 被保険者番号は保険者の中でしか一意でないので **必ず保険者番号と対で**扱う。

1 人が複数回登録される (更新のたびに行が増える) ので、取込時は
**対象月に有効なもの**を選ぶ。船橋は 544 行 = 279 名だった。
