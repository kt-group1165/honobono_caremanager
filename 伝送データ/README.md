# ほのぼの授受データの置き方

**この 1 種類だけ**。ほのぼのから出したファイルはここに合わせて置いてください。

```
伝送データ/<拠点>/訪問介護/介護/<提供年月>/ほのぼのから/  ← ほのぼのが出した国保連ファイル (正解)
                              /<提供年月>/新システム/    ← こちらが生成したもの (触らない)
伝送データ/<拠点>/訪問介護/障害/<提供年月>/…
伝送データ/<拠点>/居宅/<提供年月>/…
伝送データ/<拠点>/訪問入浴/<提供年月>/…

サービス実績データ/<拠点>/<提供年月>/訪問介護/介護/     ← MEISAI_*.csv, 介護請求(明細付)_一覧.CSV
サービス実績データ/<拠点>/<提供年月>/訪問介護/障害/
サービス実績データ/<拠点>/<提供年月>/居宅/

利用者データ/<拠点>/                                  ← 基本情報・介護保険・公費 CSV / 受給者証 PDF (フラット)
```

- `<拠点>` … 短縮名。`茂原` `大網` `五井` `姉ム` `K姉` `木更津` `花見川` `おゆみ野` `さつきが丘`
  `船橋` `八千代` `四街道` `高品` `袖ケ浦` `いすみ` `ちはら台` `中央` `市原` `やわた` `君津` `山武` `東郷`
  ⚠ **`姉ム` = ムツミヘルパーステーション / `K姉` = ＫＴ姉崎ヘルパーステーション**。別拠点なので注意
- 第 1 階層は**事業所**、その下が**制度**
  - `訪問介護/介護` … 介護保険の訪問介護 + 総合事業 (同じ事業所エントリで出るので分けない)
  - `訪問介護/障害` … 障害福祉サービス (**同じ訪問介護事業所だが事業所番号が別**)
  - `居宅` … 居宅介護支援 (ケアプラン・給付管理)
  - `訪問入浴` … 訪問入浴介護
- `<提供年月>` … `YYYYMM`。**ファイル名の年月ではなく、サービスを提供した月**

## ⚠ 提供年月は「ファイル名」ではない

ほのぼののファイル名は **処理年月** です。月遅れ請求だと中身とズレます。

```
さつきが丘 KK260801.CSV  処理 202608 / 中身は 202603  → 伝送データ/さつきが丘/訪問介護/介護/202603/…
           KK260802.CSV  処理 202608 / 中身は 202605  → …/202605/…
           KK260803.CSV  処理 202608 / 中身は 202606  → …/202606/…
```

**月ごとに別フォルダに分けてください。**混ざっていると突合が壊れます
(実際 K姉・姉ム・花見川・さつきが丘で 3〜4 か月分が 1 フォルダに同居していました)。

受け皿は全拠点分すでに作ってあります。翌月分はこれで足せます:

```bash
MONTH=202607 node migrations/scaffold_data_folders.mjs --execute
```

置き場所に迷ったら並べ替え script を流せば中身を見て振り分けます:

```bash
node migrations/normalize_data_folders.mjs            # 移動計画だけ表示
node migrations/normalize_data_folders.mjs --execute  # 実行
```

## 何を出すか

`reference_honobono_export` のメモ参照。事業者エントリごとに全部出すこと。

- 訪問介護 / 居宅: NEXT の稼働データ (MEISAI) + MORE 請求統合の国保連ファイル (KK/KY)
- 障害: MORE 請求統合の国保連ファイル (KJ/TJ/JJ) + 受給者証一覧表 PDF + 基本情報一覧表 PDF

`JK*.csv` は伝送そのものなので**取込元にはしません** (照合の正解にしか使わない)。
