# 千葉市 移動支援 (地域生活支援給付) 制度・請求仕様まとめ
# 調査日: 2026-07-14 / 出典: 千葉市公式 (下記 URL)
# 位置づけ: 障害者総合支援法の地域生活支援事業。国保連伝送 (J11/7111) には乗らない。
#           千葉市へ Excel 様式で直接請求 (窓口: 障害福祉サービス課 地域支援班 043-245-5228)

================================================================
1. 制度の骨格
================================================================
- 千葉市では「千葉市地域生活支援給付」として登録制で運営。
  対象 3 サービス: 移動支援 / 訪問入浴サービス / 日中一時支援
- 事業者は市に登録 (指定とは別)。登録は市内事業所は対面申請、登録日は申請受付日の翌々月1日。
- 請求: サービス提供月の翌月 17 日 (閉庁日なら翌開庁日) までに市へ提出。
- 様式 (Excel, 市 HP 配布):
  - 様式12 請求書 / 様式13 明細書 (サービスコード・単位数・回数を記入) / 様式4-1〜4-3 上限額管理
    2-1-1chibashitiiki_seikyuu.xls
  - 様式3-1 移動支援サービス提供実績記録票 (日付/計画・実績の開始終了時刻/算定時間/派遣人数/初回加算/利用者確認欄)
    2-1-2chibashitiiki_seikyuu.xls
- 1 単位 = 10 円 (全サービス共通・地域区分なし)
- 利用者負担: 生保世帯 0% / 市民税非課税世帯 0% / 課税世帯 10% (月上限あり、障害福祉サービスと上限額合算管理あり)
- 標準支給量: 月 25 時間
- 1人のヘルパーがマンツーマン原則。2人目従業者は同一単位 (×100%) で別コード。
- 運転中はサービス提供時間から控除。2時間未満の間隔は前後を 1 回に合算 (だから時間帯跨ぎの複合コードが存在する)。

================================================================
2. 対象者 (受給者証で支給決定)
================================================================
1 に該当 かつ 2 に該当:
1. 知的障害 / 精神障害 / 全身性障害 (身障1級かつ両上肢2級・両下肢2級以上) /
   重度視覚障害1・2級 (※同行援護優先で原則対象外) / これらに準ずると課長が認める者
2. 障害者: 障害支援区分1以上、または認定調査 1-9「移動」で見守り以上の支援が必要
   障害児: 調査項目「移動」が全介助・一部介助 (介護者が付き添えない場合に限る)
「身体介護有り」該当基準は別途 (居宅介護の通院等介助(身体伴う)対象者、または歩行/移乗/移動/排尿/排便の調査結果)

3. 単価表 (令和6年4月1日適用、算定基準より)
================================================================
基本単位 (1回につき):
  時間           身体介護有り(移動1)   身体介護無し(移動2)
  〜30分          280                  116
  〜60分          441                  215
  〜90分          640                  300
  〜120分         730                  377
  〜150分         822                  453
  〜180分         913                  529
  〜210分       1,004                  605
  以後30分ごと    +91                  +76
時間帯加算: 早朝(6-8時)・夜間(18-22時) +25% / 深夜(22-6時) +50% (1回単位で加算、四捨五入)
加算:
  - 初回加算 218単位/月1回 (移動1=024701, 移動2=027701)
  - 緊急時対応加算 109単位/月2回限度 (身体介護有りのみ, 024801)
  - 喀痰吸引等支援体制加算 109単位/日 (身体介護有りのみ, 024902)
  - 利用者負担統合上限額管理加算 164単位/月1回 (024901 / 027901)

4. サービスコード体系 (6桁、市独自)
================================================================
接頭:
  023xxx〜024xxx = 移動支援・身体介護を伴う (名称「移動1〜」)
  027xxx         = 移動支援・身体介護を伴わない (名称「移動2〜」)
  041xxx         = 訪問入浴 (041110 基本1,380 / 041111 介3人1,312 / 041701 初回218 / 041901 上限管理164 等)
  051xxx         = 日中一時支援 (051211〜 基本、051511〜 延長、送迎加算 051603=30単位/片道 等)
構造 (移動支援):
  - 時間帯区分ごとにテーブルが分かれる: 日中 / 早朝 / 夜間 / 深夜 / 深夜+早朝 /
    日中+夜間+深夜 / 早朝+日中+夜間 … (サービス間隔2時間未満で跨いだ場合の複合コード)
  - さらに「増分」コード (日中増/早朝増/夜間増/深夜増) = 210分超の 30分刻み追加分
  - 各コードに単独と「・2人」(2人目従業者) のペアがある
代表例 (身体介護有り・日中):
  023111 移動1日中0.5   280単位   023112 …0.5・2人 280
  023115 移動1日中1.0   441      023119 1.5 640   023123 2.0 730
  023127 2.5 822   023131 3.0 913   023135 3.5 1,004   023139 4.0 1,095
  … 30分刻みで +91、023191 移動1日中10.5 = 2,278 まで掲載
代表例 (身体介護無し・日中):
  027111 移動2日中0.5   116単位   027115 1.0 215   027119 1.5 300
  027123 2.0 377   027127 2.5 453   027131 3.0 529 … +76/30分、027191 10.5 = 1,669
早朝/夜間 = 基本単位×1.25 (例 023195 移動1早朝0.5 = 350)、深夜 = ×1.5 (例 023251 移動1深夜0.5 = 420)
※ 全コード一覧はコード表 PDF (28p) が正。合成単位数まで印字済なので、取込むなら PDF から表を起こす。

5.5 提出経路の調査結果 (2026-07-14)
================================================================
- 市の請求様式ページに提出媒体の明記なし (期限=翌月17日、提出先=地域支援班/施設支援班のみ)。
- ちば電子申請サービス (e-tumo 千葉市) を「地域生活支援」「移動支援」で検索 → 手続き 0 件。
  少なくとも公開手続きとしてのオンライン請求は存在しない (2026-07-14 時点)。
- 国保連の電子請求受付システムは市町村が地域生活支援事業を国保連に委託した場合のみ使える建付けだが、
  千葉市はコード表・様式とも市独自で市直接提出の案内 → 委託していないとみられる。
- 「オンラインで請求」と聞いた話は、法定給付 (居宅介護・同行援護等) の国保連インターネット請求
  (= 既に J11 伝送でやっている経路) との混同の可能性が高い。
- 要確認: 登録申請の電話予約時 (地域支援班 043-245-5228) に、地域生活支援給付の請求書類の
  提出媒体 (持参/郵送/メール添付) を確認する。

5.6 訪問入浴サービス (障害・地域生活支援給付) — 同一様式で請求
================================================================
- KT Group は訪問入浴も運営 → 千葉市分は移動支援と同じ様式12/13 + 様式3-2 実績記録票で請求できる。
- コードは 041xxx の 12 個のみ (時間帯・複合コードなし):
  041110 基本 1,380 / 041111 介護職員3人 1,312 / 041112 同一減算Ⅰ 1,242 / 041113 同一減算Ⅱ 1,173
  041120 中止(清拭・部分浴) 1,242 / 041121 中止・3人 1,181
  041501-041503 サービス提供体制強化加算Ⅰ/Ⅱ/Ⅲ 48/40/14 / 041701 初回加算 218 (月1回) / 041901 上限額管理 164
- 算定ルール: 週2回限度 (日曜起点の週、3回目以降は当月末まで算定不可、繰越例外あり — 算定基準 2(1))
- 様式3-2 実績記録票の列: 実施日/曜日、開始・終了時間、入浴方法 (実施/中止)、
  中止の理由 (1=本人の都合/2=身体の状況/3=その他)、利用者確認欄、備考
- 介護保険の訪問入浴介護 (kaigo_bath_visit_records, 2026-07-08 実装) とは制度も請求経路も別物。
  ただし記録 UI は bath-records 縦割りの流用が効く。

5.7 Phase 1 実装状況 (2026-07-14)
================================================================
- system 値は '地域生活支援' に確定 (既存 CHECK 値が日本語のため。当初案 'chiba_chiiki' は不採用)
- コード表 28p を全ページ表起こし済み (単一時間帯系列は生成+検算、複合 151 組は明示定義)
  → seed_chiiki_chiba_service_codes.mjs (703 件: 移動支援 692 + 訪問入浴 11。日中一時支援は未投入)
- 複合コードの丸めは「区分ごとに四捨五入して合算」(合算後丸めでは 023539 等が 1 ズレる)
- DB: chiiki_chiba_v1.sql (★未適用) = system CHECK 追加 + kaigo_idou_shien_records + bath scheme 列
- UI: 業務種別「移動支援」(第4縦割り) + /idou-records 記録ページ + bath-records に制度フラグ
- コード解決 (src/lib/idou-shien-code.ts) は単一時間帯のみ。時間帯跨ぎ複合・増分(2回目合算)・
  日跨ぎは Phase 2 の算定エンジンで対応 (記録は保存可、コード未確定の警告表示)
- offices に service_type='移動支援' の事業所行を作って利用者を assign する運用
  (offices.service_type の CHECK 有無は適用時に要確認 — chiiki_chiba_v1.sql 末尾コメント参照)

6. kaigo-app 実装への示唆
================================================================
- 請求経路が「伝送」ではなく「Excel 様式の市直接提出」→ 既存 7111/J11 builder は流用不可。
  様式12/13 + 実績記録票の帳票 generator (既存の様式第一/第二印刷系の作りに近い) を新設する形。
- コードは kaigo_service_codes に system='chiba_chiiki' 等の世代管理で投入可能 (validInMonth フィルタ流用)。
- 実績記録は visit_records 系と同構造 (開始/終了/算定時間/派遣人数/初回加算/利用者確認)。
- 時間帯跨ぎ・2時間ルールの複合コード解決ロジックだけ独自 (開始終了時刻から日中/早朝/夜間/深夜への分解)。
- 上限額管理 (障害福祉サービスと合算) が絡む。既存の障害上限管理と統合設計が必要。
