■ ファイル形式 (共通編 1.2.1/1.2.2)
- CSV 可変長 / Shift_JIS / CRLF (0x0D0A)
- ファイル名: 英字で始まる半角英数字 8 桁以内 + .CSV
- コントロールレコード:
    1,連番,ボリューム通番(0),データ件数,データ種別(3桁),市町村番号(事業所提出は0),
    事業所番号(10),都道府県番号(0),媒体区分(1=伝送),処理対象年月(YYYYMM=審査月),予備(空)
  ※設定例: 1,1,0,123,999,0,1111111111,0,1,201805,
- データレコード: 2,連番,<交換情報のCSV項目...>
- エンドレコード: 3,連番
- データ種別 = 先頭データレコードの交換情報識別番号の上3桁 (J11 / J41 / J61)
- 処理対象年月 = 国保連で電算処理する年月 (提供月の翌月)

    項8 開始年月日 = 「**一連とみなされる利用契約の下で最初にサービスを提供した日付**」
      (請求の都度記載)。⚠ 契約日でも当月の初回訪問日でもない。
      原典の例: 9/1 契約 → 9/15 契約支給量を変更 → 9/3〜9/10 提供
                → 開始年月日は **9/3** (契約支給量を変えても動かない)
      → 当方は「当月の初回訪問日」を出しており誤り。契約が続く限り遡って
        最初の提供日を出す必要がある (2026-08-07 四街道7月で 7名全員が不一致)

  設定ルール (設定例③ 重度訪問介護 No.1〜12, PDF p164-175):
    - 提供通番: 重訪は 1 日 (0時〜24時) の所要時間を通算して算定するため
      「同一日のサービス提供 = 同一番号」。2 人派遣で行が分かれる場合は別番号
    - 算定時間数 (明細16): 1 日の通算時間を同一通番の最終行 (日付昇順・開始時間昇順) に
      まとめて設定。他の行は空欄
    - 0 時またぎ: 0 時で行を分ける。最小単位 (30分) 内でまたがった分は開始時間が属する
      日の分として設定
    - 同一時間の 2 人派遣: 1 行 + 派遣人数 2 (算定時間数は 1 人分)。時間がずれた場合は
      2 行 (別通番) + サービス提供回数 1/2 + 各行 派遣人数 1
    - 基本19 算定時間数計: 延べ時間 (2 人派遣は 2 人分。例: 10h×2人 → 20.0h)
    - 移動 (明細18): 移動介護の「算定」時間数を通番の最終行に設定 (3h 以上→4h)。
      移動介護分の合計は基本33
  決定サービスコード (J121 契約情報用):
    121000 重度包括支援対象者決定 / 122000 障害支援区分6該当者決定 / 123000 その他決定 /
    120901 加算移動介護 (移動介護ありの場合の契約支給量)

■ 未検証事項 (伝送ソフト/電子請求受付システムの取込チェックで確認)
  - J121 基本情報 8 氏名カナは任意のため未設定で出力
      ※埋める場合は clients.furigana → 半角カタカナ変換が必須 (全角/ひらがなだと取込エラーになる)。
        空欄は仕様上valid なので安全側で未設定のまま。
  - 算定時間数は実提供時間 (duration_minutes) をそのまま設定 (30分単位丸めは未実装)
      ※丸め要否・方式は取込チェックで確定してから実装する (推測で変えると請求額を誤るため据置)
  - [解決済 2026-07-03] J411 明細の他事業所 総費用額: 自事業所上限管理の調整計算UIに
      総費用額の入力欄を追加 (shogai-seikyu-content.tsx)。管理結果3で office_lines.total_amount が
      J411明細9に反映される。※過去に保存済の office_lines は total_amount=0 のまま → 再入力・再保存が必要
  - 契約支給量は受給者証ページのテキストから数値抽出 (カテゴリ別表記推奨: 例「身体30 家事20」)
  - [重訪 0301 関連 2026-07 追加]
    - 重訪の契約情報レコード (決定コード 121000/122000/123000 の選択) は受給者証の
      支給決定内容を構造化して保持していないため未出力 (warning で通知)
    - 移動介護 (基本33 / 明細18)・入院中提供 (明細36)・重訪の加算欄 (基本112/113/115/147,
      明細69/70/72/91) は実績データに保持がなく空欄 (該当加算の請求明細があれば warning)
    - 「・２人」(派遣人数2)「・同行１/２」(同行支援) はマスタのサービス名から判定。
      同行１→1 / 同行２→2 のコード対応は取込チェックで要確認
    - 二人派遣で時間がずれた場合の行分割 (提供回数 1/2) はデータ上判別できないため未対応
      (同一時間の・２人コードのみ対応)
    - 同月に居宅介護+重訪が混在する場合の J121 集計/J111 の負担額按分は未検証
      (種類別費用は単位数比、端数と負担額は先頭種類に集約。warning で通知)
