# 本番移行に必要なデータ一覧

**目的**: 現在はテストでデータを段階的に移しているが、本番切替の際には
ゼロから入れ直すことになる。その際に「何のデータが要るか」を漏れなく
洗い出しておくためのチェックリスト。

**位置づけ**: [MIGRATION_HONOBONO_EXPORT.md](MIGRATION_HONOBONO_EXPORT.md) が
「ほのぼのから何がどう出せるか」の詳細な手順書。こちらはその手前の
「本番移行にはどのデータ種別が要るか」を俯瞰する一覧。

**作成**: 2026-09-01。事業所マスタ整理・データ取込カバレッジ監査 (4並列調査) の結果を踏まえて作成。

---

## 1. 事業所・法人

| データ | 内容 | 入手方法 |
|---|---|---|
| 自社事業所マスタ | 名称・種別・事業所番号(介護/障害/総合事業ごとに別番号) | ほのぼの依存ではなく社内で確定管理(`offices`) |
| 他社事業所(居宅・ケアマネ) | 名称・事業所番号・法人 | 厚労省公表データ(opendata、2026-09-01整備済み)+ 利用票の事業所名で補完 |
| サービス提供事業所(福祉用具等) | 名称・法人 | opendata + 利用票の`provider`欄(2026-09-01時点で1,245件抽出済み、要クリーニング) |
| 法人マスタ | 法人番号・名称 | opendataから自動導出 |

## 2. 利用者

| データ | 内容 | 入手方法 |
|---|---|---|
| 基本情報 | 氏名・生年月日・住所・電話・被保険者番号等 | 利用者管理→CSV「基本情報」**絞込み=すべて**(有のみだと終了者が落ちる) |
| 介護保険認定 | 要介護度・認定期間・限度額 | 「介護保険」CSV **範囲=全件 / 参照対象=保険と認定** |
| 障害受給者証 | 受給者証番号・支給量等 | 別ログインの障害システム。**more【利用者管理】CSV出力(SRD18、124列)で取得可能**(PDF解析不要と判明済み) |
| 公費 | 公費負担者番号等 | 「公費」CSV |
| 負担割合証 | 負担割合 | 「負担割合証等」CSV |
| 事業所への割当 | どの拠点の利用者か | 上記CSVの取込scriptが自動生成 |

## 3. 職員

| データ | 内容 | 入手方法 |
|---|---|---|
| 職員マスタ | 氏名・職種・所属事業所 | **ほのぼのに出力機能があるか未確認**(2026-09-01の調査で判明した空白)。無ければ給与システムのCSVで代用。⚠ 給与CSV(`private-data/payroll-data/従業員/`)は訪問介護の拠点のみ収録で、居宅介護支援・訪問入浴の職員は含まれない(2026-09-01実測: 高品の給与CSVは訪問介護の事業所番号のみ) |
| ケアマネジャー | 担当利用者との紐付け | ケアプラン取込の副産物として自動生成、または専用の出力があれば直接 |

## 4. ケアマネジメント書類(居宅介護支援)

| データ | 内容 | 入手方法 |
|---|---|---|
| ケアプラン第1・2表 | 方針・週間サービス | ケアマネ→CSV「計画書（1）」「計画書（2）A様式」 |
| 第3表(週間・日課計画) | — | CSV化不可。印刷→PDF一括保存ルート([MIGRATION_HONOBONO_EXPORT.md §3](MIGRATION_HONOBONO_EXPORT.md)参照) |
| 支援経過 | 面談記録等 | CSV化不可。印刷→PDF→座標抽出(高品のみ実施済み) |
| アセスメント | 生活状況等 | 同上 |
| 利用票・提供票(第6表) | 月次サービス予定 | 同上(全15拠点、主に2026-06分のみ) |
| 利用票別表(第7表) | 限度額内訳 | **第6表と同じ操作で連続出力必須**(単独では利用者と紐付け不可と判明済み) |
| 給付管理票 | 給付実績 | 伝送(KY/KK)から取込 |

## 5. サービス提供実績(訪問介護等)

| データ | 内容 | 入手方法 |
|---|---|---|
| 訪問予定・実績 | 日々のサービス提供記録 | NEXT賃金集計のMEISAI CSV + 介護請求(明細付)一覧CSVを突合 |
| 訪問介護計画書 | 訪問時の手順 | 上記実績から自動生成可能(既存ロジックあり) |

## 6. 請求・伝送関連(過去分が必要な範囲で)

| データ | 内容 | 入手方法 |
|---|---|---|
| 過去の請求実績 | 月次請求額の履歴 | 伝送(KJ/KK)から取込 |
| 上限額管理結果票 | 他事業所が上限管理者の場合の按分結果 | マスタ化されておらず書類を見て手入力するしかない |
