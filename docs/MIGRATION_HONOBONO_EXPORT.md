# ほのぼの → 新システム 移行データ 総ざらい

**目的**: 移行時に「過去 N ヶ月ぶんのデータを全部持ってくる」ための、
出力元・出力手順・取込先の対応表。伝送検証はこの一部でしかない。

**状態**: 🚧 作成中 (2026-08-30 開始)。棚卸しが終わった項目から埋めていく。

---

## 0. 前提

- ほのぼのは **Citrix 経由**で動く。ファイル出力先は `\\Client\C$\...` (= 10F の PC)
- 受け渡しは Box 経由

```
ほのぼの側   \\Client\C$\Users\KTHonsya\Box\10F内共有\ほのぼのから出力
こちら       C:\Users\domen-PC\Box\10F内共有\ほのぼのから出力
```

- **出力先は帳票ごとに別に記憶される**。初期値がデタラメ (存在しないパス) のことがあり、
  その場合は「ファイルの書き込みに失敗しました」で止まる
- リモート操作では **Shift が伝わらない**ので、パスは打てない (`\`→`]` / `$`→`4` /
  大文字→小文字 / 日本語は消滅)。**ほのぼの側でパスをコピーしておいて右クリック貼り付け**する

## 1. システムの分かれ方

| システム | 何が入っているか |
|---|---|
| **ほのぼの NEXT** | 介護保険 (居宅介護支援 / 訪問介護 / 訪問入浴 / 総合事業)。利用者マスタもこちら |
| **ほのぼの more** | 障害福祉。利用者マスタは別 (障害の受給者証・支給決定) |

more の中はさらに 2 本立て。

| exe | 役割 |
|---|---|
| 障がい福祉**サービス費等請求**システム | 事業所ごと。利用者台帳・実績・利用料。**CSV出力**あり |
| 障がい福祉**請求統合**システム | 法人横断。伝送ファイル作成・上限管理・明細書。**CSV** タブあり |

### 2.3 NEXT【賃金集計】→ 稼働データ

介護保険の訪問介護実績。**NEXT の「賃金集計」**から出す (MORE には無い)。

```

**エントリごとに出す**。

### 2.6 more【障がい福祉利用者管理システム】→ CSV出力 ★重要

**受給者証・支給決定が CSV で出せる。** これまで PDF を parse していた
(`parse_shougai_certs.py`) 工程が**丸ごと不要になる**。

到達経路: 障がい福祉サービス費等請求システム → ツールバー **利用者管理** →
**CSV出力**

出せる帳票 (28 種):

```
基本情報      基本状況    家族構成    病歴      判定情報    生活状況   利用状況一覧
身体状況      精神状況    生育歴      学歴      職歴        施設歴     障害手帳
療育手帳      精神手帳    年金手帳    原爆手帳  保険情報    受給者証   事業者記入欄
口座情報      利用登録    私物管理    面会      外出        外泊       事業所詳細設定
```

**受給者証 (SRD18.CSV) は 124 列**。PDF から読んでいた項目が全部入っている。

```
 17 受給者証種別   18 施設種別   19 受給者証番号   20 交付年月日
 21 支給市町村名   22 開始日     23 終了日        24 障害程度区分
 25 身体介護支給量  26 家事援助   27 通院介助(移動介護)  28 通院介助(移動)・身体
 29 日常生活      50 乗降介助   51 行動援護      52 外出介護   53 外出・身体
 67 重訪(重度包括) 68 重訪(区分６) 69 重訪(その他)  71 重度包括
 93 同行援護支給量 94 同行援護・身体
 55 負担率(%)     56 所得区分   57 利用者負担上限月額   58 軽減後上限月額
 64 上限管理事業者 66 境界層措置 89 同一世帯の複数利用者で上限管理

**期間** = その期間に有効な受給者証。**1 人が世代ごとに複数行**。
茂原 (リンクスヘルパーステーション) を R8/1/1〜R8/8/31 で 59 件。

実証: 狩野佑佳の 18歳到達での切替が正しく 2 行で出る。

```
1242311080  2025/07/01〜2026/03/31  区分なし  低所得1  上限 4,600円
1242313920  2026/04/01〜2026/06/30  区分６    低所得1  上限    0円
```

⚠ **事業所ごと**。事業所切替で回す必要がある。

### 2.7 more【障がい福祉請求統合システム】

左のタブ: データ収集 / 合算処理 / 負担一覧 / 上限管理 / 集計 / 明細書 /
**データ作成** / 統計 / **CSV**

- **データ作成** = 伝送ファイル (KJ/TJ/JJ) の書き出し
- **CSV** = 明細書 / 明細書(明細付) / 明細書(集計付) / 計画作成請求書 /
  計画作成請求書(明細付) / 請求書 / 請求書(明細付) / 利用者負担額一覧表 /
  負担上限額結果票 / 負担上限額結果票(明細付) / 明細書(処遇改善付) /
  計画作成請求書（サービス付） / 負担上限複数 / 負担上限複数(明細付)

⚠ どれも **「データ収集」を先に実行**しないと 0 件。収集対象事業者は
**サービス費等請求システム側で「適用」にした事業所**に連動する。

## 5. 取込の実行順序 (介護・確立済み)

```
1. import_meisai_step1_clients.mjs      利用者・認定  ← 認定を入れ直すので必ず最初
2. import_meisai_kohi.mjs               公費
3. link_caremanager_office.mjs          担当居宅介護支援事業所 (伝送 項19/20)
4. import_meisai_service_start_date.mjs サービス利用開始年月日 (項21)
5. import_meisai_visit_records.mjs      介護実績   ※OFFICE_BN で指定 (OFFICE_ID は効かない)
6. import_meisai_sougou_records.mjs     総合事業
7. import_meisai_addon_lines.mjs        加算行
8. import_meisai_plan_units.mjs         計画単位数
9. fix_copay_rate.mjs                   負担割合
```

障害は STEP1 の後に `parse_shougai_certs.py` → `import_honobono_shougai_oami.mjs`
→ `import_meisai_shougai_records.mjs`。
