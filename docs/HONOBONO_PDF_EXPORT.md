# ほのぼの → 帳票を PDF で一括出力する手順

支援経過・会議録・モニタリング・アセスメント・主治医意見書は **CSV では出せない**
(ケアマネ → CSV タブは 計画書(1)/(2)/A様式 の 4 つだけ)。
これらは **印刷 → PDF** で移す。

> ⚠ 以前の引き継ぎに「一括印刷は 1 人ずつ保存が要り実用外」とあったのは **誤り**。
> 印刷ダイアログの **利用者選択を「複数」**にすれば全員分を **1 つの PDF** に出せる。
> 保存ダイアログは最初の 1 回だけ。2026-08-31 に実証済み。

---

## 手順

### 1. 対象の利用者を見える状態にする

ほのぼの NEXT → **利用者管理 → 事業所切替**

- 1 拠点だけ出す → その拠点の事業所グループにチェック
- 全社から探す → **「(グループ選択無し)」**を選ぶと【複数事業所適用中】になり
  全事業所 7,902 名が対象になる

### 2. 帳票を開く

**ケアマネ** タブ → 出したい帳票のサブタブ

```
進捗管理 / アセスメント / 課題整理総括 / 課題分析 / 計画書 / 会議録 /
利用・提供票 / モニタリング / 支援経過記録 / 認定調査 / 主治医意見書 / 情報連携 / CSV
```

⚠ サブタブは **2 回クリック**しないと切り替わらないことがある (リモート越しの取りこぼし)。
   画面が変わらなければもう一度押す。

### 3. 印刷ダイアログを開く

上部の **印刷** ボタン。

### 4. プリンタを PDF にする

**プリンタ設定** → 一覧の先頭 **Microsoft Print to PDF** → OK

⚠ 一覧は名前が途中で切れている。横スクロールしないと
   `Microsoft Print to PDF` か `RICOH…` か判別できない。

### 5. 利用者選択を「複数」にする

右上の **利用者選択 ○単一 / ●複数** → **複数**

「全選択 / 全解除 / 反転」が出る。行をクリックすると 1 人ずつ選べる。
下に `3/ 7900 人` のように選択数が出る。

### 6. 期間を決める

**期間** 欄 (既定は処理期間)。支援経過なら移行したい範囲にする。

### 7. 印刷 → 保存

**印刷** → 部数とページ設定が出る → **印刷** → 保存ダイアログ

- 保存先は既に `ほのぼのから出力` フォルダになっている
- ファイル名は **半角英数**で入れる (CRD 越しに日本語・記号は打てない)
- 保存すると結果一覧が出る

```
青木 春夫   印刷済み
青木 英夫   データがありません
青澤 厚     データがありません
```

**データが無い人は自動で飛ばされる**ので、全選択して出して構わない。

### 8. こちらで受け取る

```
ほのぼの側   \\Client\C$\Users\KTHonsya\Box\10F内共有\ほのぼのから出力
こちら       C:\Users\domen-PC\Box\10F内共有\ほのぼのから出力
```

Box が同期するので数十秒で見える。

## PDF から取り込む

テキストは普通に抽出できる (画像 PDF ではない)。

```python
import pypdf
r = pypdf.PdfReader("shienkeika.pdf")
print(r.pages[0].extract_text())
```

支援経過の 1 ページ目はこう出る。

```
殿
作成年月日令和 7年12月16日
居宅サービス計画作成者氏名ほのぼの 管理者
Hana居宅高品
青木 春夫
令和 8年 8月31日居宅介護支援経過
利用者名
要介護３要介護度
内　　　　　容年月日 項　目
居宅契約・ア 二女宅を訪問し、本人と二女夫婦と面R 7/12/16
セスメント 談する。…
```

⚠ **段組がそのまま出るので行が混ざる**。年月日・項目・内容が 1 行に混在する。
  素朴な正規表現では切れないので、**Claude に読ませて JSON にする**のが確実。
  取込 script の型は `migrations/import_honobono_careplans.mjs` にある
  (PDF → Claude 抽出 JSON → dry-run script)。

⚠ 利用者の同定は **氏名だけでは危ない** (同姓同名が実在する)。
  PDF のヘッダーに利用者番号が無いので、**1 ファイル 1 拠点**にして
  拠点 + 氏名で引くか、少人数ずつ出してファイル名に番号を入れる。
